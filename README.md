# salam

## ساختار فایل‌های `js/`

```text
js/
├── assets.js        ← متریال، جئومتری و تکسچرهای مشترک
├── audio.js         ← صدا و افکت‌های صوتی
├── camera.js        ← دنبال‌کردن بازیکن با دوربین
├── carModels.js     ← مدل‌ها و مشخصات ماشین‌ها
├── civilians.js     ← ترافیک غیرنظامی و هوش مصنوعی آن‌ها
├── collisions.js    ← تشخیص و حل برخوردها (SAT)
├── config.js        ← سختی‌ها، سطح پلیس‌ها و پارامترهای بازی
├── damage.js        ← آسیب، نابودی ماشین‌ها و افکت برخورد
├── environment.js   ← چرخه‌ی شب‌وروز، باران و مه
├── flow.js          ← شروع، بازنشانی، پایان و مکث بازی
├── helicopter.js    ← هلیکوپتر پلیس و تعقیب هوایی
├── input.js         ← ورودی کیبورد و لمس
├── main.js          ← نقطه‌ی شروع و حلقه‌ی اصلی بازی
├── particles.js     ← ذرات و افکت‌های بصری
├── police.js        ← هوش مصنوعی و تولید نیروهای پلیس
├── props.js         ← اشیای شکستنی محیط
├── renderer.js      ← renderer، صحنه، دوربین، نورها و آسمان
├── roadblock.js     ← ایجاد و استقرار سدهای جاده‌ای پلیس
├── rules.js         ← سطح تعقیب، ستاره‌ها و امتیاز near miss
├── spikes.js        ← نوار میخ‌دار پلیس (spike strip)
├── state.js         ← وضعیت بازی، آرایه‌ها، بازیکن و sight پلیس
├── trafficLights.js ← ساخت چراغ‌های تقاطع و چرخه‌ی تغییر فاز آن‌ها
├── trees.js         ← درخت‌های قابل تخریب
├── ui.js            ← HUD، رادار، toast و دکمه‌های تست آب‌وهوا
├── update.js        ← به‌روزرسانی اصلی بازی در هر فریم
├── utils.js         ← ثابت‌ها و توابع کمکی
├── vehicle.js       ← ساخت ماشین و فیزیک رانندگی
└── world.js         ← شهر پروسیجرال و مدیریت chunkها
```
